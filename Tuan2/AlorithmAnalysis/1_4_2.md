Sửa chương trình ThreeSum để chạy đúng ngay cả khi các giá trị int lớn đến mức có thể gây tràn số.

**Lời Giải**

Trong thuật toán ThreeSum, điều kiện kiểm tra sẽ là : 

`if (a[i] + a[j] + a[k] == 0) { ... }1`

Khi đó nếu 3 giá trị a[i] a[j] a[k] rất lớn thì có thể dãn đến hiện tượng tràn số

**CÁCH KHẮC PHỤC**

Để khắc phục trường hợp này ta có thể ép kiểu sang long trước khi cộng

```
    public class ThreeSum {
    public static int count(int[] a) {
        int n = a.length;
        int count = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    if ((long) a[i] + a[j] + a[k] == 0L) {
                        count++;
                    }
                }
            }
        }
        return count;
    }
}
```
