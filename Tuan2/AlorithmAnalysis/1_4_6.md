1.4.6 Cho biết bậc tăng của thời gian chạy (theo hàm của N) của mỗi đoạn code sau:

**Lời Giải**

a)
```
        int sum = 0;
        for (int n = N; n > 0; n /= 2) 
            for (int i = 0; i < n; i++) 
                sum++;
```

Vòng lặp ngoài giảm một nửa giá trị sau mỗi bước: $n = N, N/2, N/4, \dots, 1$.

Tổng số phép toán: $N + \frac{N}{2} + \frac{N}{4} + \dots \le 2N \sim N$.

b)

```
        int sum = 0;
        for (int i = 1; i < N; i *= 2) 
            for (int j = 0; j < i; j++) 
                sum++;
```

Biến $i$ nhân đôi sau mỗi bước: $i = 1, 2, 4, 8, \dots, 2^k < N$.

Tổng số phép toán: $1 + 2 + 4 + \dots + 2^k = 2^{k+1} - 1 \sim 2N \sim N$.

c)

```
        int sum = 0;
        for (int i = 1; i < N; i *= 2) 
            for (int j = 0; j < N; j++) 
                sum++;
```

Vòng lặp ngoài chạy $\sim \lg N$ lần (do $i$ nhân đôi liên tục cho đến khi chạm ngưỡng $N$).

Vòng lặp trong mỗi lần đều chạy đúng $N$ bước độc lập với $i$. 

Tổng số phép toán: $N \times \lg N \sim N \lg N$.
